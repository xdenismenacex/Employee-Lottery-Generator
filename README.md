# Employee of the Month Lottery

A simple Python program that picks a random Employee of the Month from a list of candidates.

## What it does

1. Shows a numbered list of all the candidates.
2. Prints the total number of candidates.
3. Picks one winner at random and announces them.

## Example output

Good luck to all the candidates in this month's Employee of the Month competition!
1. NAME1
2. NAME2
3. NAME3
4. NAME4
5. NAME5

Total candidates: 5

🎉 This month's winner is: NAME3. Congratulations, claim your bonus from your team leader! 🎉

## How to run it

1. Open a new notebook at colab.research.google.com, or use any Python editor.
2. Paste the code and run it.

To use your own team, replace NAME1 to NAME5 in the `candidates` list with real names. You can add or remove as many names as you like.
